# 🤖 SmartRoute AI - RouteLLM RAG System

An AI-powered document question-answering and summarization system built using:

- Streamlit
- LlamaIndex
- Groq LLM
- HuggingFace Embeddings
- RAG (Retrieval Augmented Generation)
- Router Query Engine


# 🚀 Features

✅ Upload PDF documents  
✅ AI-generated document summaries  
✅ Ask questions from uploaded documents  
✅ Semantic search using vector embeddings  
✅ Intelligent routing between summarization and retrieval  
✅ Fast responses using Groq LLM  


# 🧠 Tech Stack

| Technology | Purpose |
|---|---|
| Streamlit | Frontend UI |
| LlamaIndex | RAG Pipeline |
| Groq | Large Language Model |
| HuggingFace | Embedding Model |
| VectorStoreIndex | Semantic Retrieval |
| SummaryIndex | Document Summarization |
| RouterQueryEngine | Smart Query Routing |
